## Contribute

We invite you to contribute by [opening issues](https://github.com/datalayer/jupyter-ui/issues) and submitting [pull requests](https://github.com/datalayer/jupyter-ui/pulls) for any question, problem or to discuss adding your solution as a provider.

We welcome contributions of all kinds, including:

- 🐛 Bug fixes
- 📝 Improvements to existing features or documentation
- 🔧 New feature development

Your contributions help us improve the project and make it more useful for everyone!

See more in [CONTRIBUTING.md](https://github.com/datalayer/jupyter-ui/blob/main/CONTRIBUTING.md)
